# E-Commerce Store Backend

A relational database design for an e-commerce store backend — customers, products, orders, shipping, billing, and payments.

## Files

- `project.sql` — SQL schema (tables, keys, constraints)
- `DB project ERD.drawio` — Editable ERD (open at [app.diagrams.net](https://app.diagrams.net))
- `DB project mapping.drawio` — Editable mapping / schema (open at [app.diagrams.net](https://app.diagrams.net))

## Main Tables

Department, Employee, Customer, Customer_Phone, Factory, Products, Orders, Order_Product, Bill, Shipping, Payment


## Status

Student project for practicing database design and ER modeling.
